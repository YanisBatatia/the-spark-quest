# The Spark Quest

A fast, static catalogue of 101 experiences. The site has four main screens: Welcome, Explore, Experience, and My list. Explore filters and the saved list run entirely in the browser; saved items stay in that browser's local storage. There is no account or server database.

## Run locally

Use Node 22.12 or newer and pnpm. The lockfile fixes the dependency versions used by GitHub Actions.

```sh
pnpm install --frozen-lockfile
pnpm run validate
pnpm run dev
```

`pnpm run build` creates the static site in `dist/`. The validator requires all 101 records, their images and credits, and the 101 location maps.

## Publish on GitHub Pages

This directory is the repository root for `YanisBatatia/the-spark-quest`. Push the `main` branch to a **public** GitHub repository, then set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The workflow in `.github/workflows/deploy.yml` builds and deploys on each push to `main`. The expected address is `https://yanisbatatia.github.io/the-spark-quest/`.

For a local build with the same path prefix, run:

```sh
GITHUB_REPOSITORY=YanisBatatia/the-spark-quest pnpm run build
pnpm run preview:pages
```

All internal links and static map URLs use Astro's configured base path. The site needs no runtime hosting beyond GitHub Pages.

Each detail page starts with a small illustrated map. Its interactive OpenStreetMap view loads only after the visitor chooses **Explore interactive map**; the full map link works without JavaScript. Coordinates indicate an approximate area rather than a venue entrance.

## Content and image sources

Experience copy lives in `src/data/experiences/`. The public site does not include the source PDF. Approximate map coordinates and map SVGs live in `src/data/map-coordinates.json` and `public/maps/`. The maps use Natural Earth land shapes and OpenStreetMap geocoding data and credit both on each detail page.

Photographs come from the site owner's selected `exp-image` folder, Wikimedia Commons, and Unsplash. The owner confirmed permission to publish the selected photographs. Source links and known authors or license terms are in `src/data/image-credits.json` and on the site's Image credits page. Three original illustrations are identified in `src/lib/featured-images.ts`. Photos can illustrate a related scene rather than the exact experience, as stated on detail pages. Image crops and WebP variants are generated by Astro at build time. `scripts/import_user_images.mjs` can reimport the owner's selected images when the sibling `exp-image` folder is present.

Dates, prices, accessibility, programs, and availability can change. Each experience includes a brief "Good to know" note and selected provider links so visitors can confirm details before planning.
